Autonomous Lane Detection

A deep dive into computer vision for autonomous driving. I built a classical lane-detection pipeline in OpenCV and picked up a lot of vision theory along the way.

Pipeline

  1. Camera calibration. Find chessboard corners in a set of calibration photos, estimate the camera matrix and distortion coefficients, and undistort every frame.
  2. Thresholding. Build a binary mask of likely lane pixels by combining a Sobel gradient threshold (strong horizontal gradients at lane-like angles) with a color threshold in HLS space (high saturation, which picks out painted lines).
  3. Bird's-eye view. Warp the mask with a perspective transform so the lane lines look roughly parallel from above.
  4. Finding the lines. On the first frame, a histogram of the bottom half of the image locates each line's base. Nine sliding windows then follow each line up the image. On later frames, the search stays within a margin of the previous fit.
  5. Fitting. Fit a second-order polynomial x = ay2 + by + c to each line's pixels, and convert from pixels to meters to estimate each line's radius of curvature.
  6. Overlay. Fill the region between the lines, warp it back into the original view, and blend it onto the frame.
