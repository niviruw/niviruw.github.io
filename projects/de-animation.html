Approach

  1. Detect and track "anchor" features using the Kanade-Lucas-Tomasi feature tracker.
  2. Define a 64 x 32 rectilinear mesh over each frame and represent each feature location as a bilinear interpolation of the vertices of the mesh quad that encloses it.
  3. Set up and solve for the initial warp, following Equation 3 in Bai et al.
  4. Texture map the input video onto the initial output mesh.
  5. Use the initial warp as input and detect "floating" feature tracks.
  6. Solve for the refined warp, following Equation 5 in Bai et al.
  7. Texture map the input video onto the refined mesh.
